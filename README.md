# Zino Racing Engine

A racing-game development environment built on **Godot 4.7**: a standalone desktop editor
(the Zino Editor), a shared racing runtime, and a Godot editor plugin connected over an
authenticated local bridge. Default graphics: **Ultra Max**. Primary export target: iOS. **Version 1.1.0 — all 11 phases complete.**

**Easiest start:** Home › **✨ Make a Game** — five clicks to a playable racing game, then tune it on the
Game tab, add rules with block recipes, and follow the Coach. Switch on **Advanced** for every pro tool.

- Release: `.\tools\build-release.ps1` → `builds\ZinoEditor\Zino.exe` (opens on the Home screen)

- Start: `.\tools\run-editor.ps1` — see [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md)
- Tests: `.\tools\run-tests.ps1`
