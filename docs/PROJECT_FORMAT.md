# Zino Project Format v1

A Zino project folder is also a valid Godot 4 project.

```
MyRacingGame/
  project.zino              Zino manifest (JSON)
  project.godot             Godot project file (generated; main scene = Zino runtime entry)
  icon.svg  README.md  .gitignore
  Config/graphics.json      gameOutput / editorPreview presets
  Assets/                   SOURCE assets (never modified by Zino)
    Vehicles/ Tracks/ Materials/ Textures/ Audio/ Environment/ UI/
  Scenes/Main.zscene        Zino scenes (JSON) — the source of truth
  Worlds/                   Godot scenes generated by the Zino Bridge (.tscn)
  Scripts/ Blocks/ Plugins/ Godot scripts, block programs (Phase 3), project plugins
  Builds/                   Export output (git-ignored)
  Cache/                    autosave/, bridge session file (git-ignored)
  addons/zino_runtime/      Zino runtime (copied from the engine; Project > Repair Add-ons)
  addons/zino_bridge/       Zino Bridge Godot editor plugin
```

The original brief's `Blueprints/` folder has no Godot equivalent; Godot scripts go in `Scripts/`.

## project.zino
```json
{
  "format": "zino-project", "formatVersion": 1,
  "engine": {"name": "Zino Racing Engine", "version": "0.1.0", "godotVersion": "4.7.2"},
  "project": {"name": "MyRacingGame", "version": "0.1.0", "created": "…Z", "modified": "…Z",
              "bundleIdentifier": "com.example.myracinggame"},
  "template": "circuit", "gameType": "circuit", "physicsProfile": "circuit",
  "startingEnvironment": "day",
  "graphics": {"gameOutput": "ultraMax", "editorPreview": "ultraMax"},
  "targetPlatforms": ["ios", "windows"],
  "startScene": "Scenes/Main.zscene", "scenes": ["Scenes/Main.zscene"],
  "modules": {"vehicles": true, "tracks": true, "race": true, "blocks": false, "openWorld": false},
  "dependencies": {"zino_runtime": "0.1.0", "zino_bridge": "0.1.0"},
  "blockScripts": [], "vehicleProfiles": ["circuit"], "tracks": ["Circuit Road"]
}
```

## *.zscene
```json
{ "format": "zino-scene", "formatVersion": 1, "name": "Main",
  "settings": {"environmentPreset": "day", "exposure": 1.0, "ambientIntensity": 1.0,
               "fogEnabled": true, "fogDensity": 0.0008, "fogColor": [r,g,b,a]},
  "entities": [ … ] }
```

Entity (all types):
```json
{ "id": "e_k3j9x0q2ab", "name": "Player Car", "type": "vehicle", "parentId": null, "active": true,
  "transform": {"position": [x,y,z], "rotation": [x,y,z], "scale": [x,y,z]}, …component… }
```
Space: metres, +Y up, −Z forward, rotation in Euler degrees (Godot YXZ).

| type | component | key fields |
|---|---|---|
| `empty` | — | |
| `primitive` | `mesh` | `primitive` (cube/sphere/cylinder/capsule/plane, 1 m), `material` {preset,color,metallic,roughness}, `castShadows`, `collider` |
| `light` | `light` | `kind` (directional/point/spot), `color`, `intensity`, `range`, `spotAngle`, `shadows` |
| `camera` | `camera` | `fov`, `near`, `far`, `orthographic`, `orthoSize`, `mode` (fixed/chase), `targetId`, `followDistance`, `followHeight`, `lookAhead`, `smoothing` |
| `vehicle` | `vehicle` | `playerControlled`, `spec` {profile, massKg, bodySize, bodyColor, centerOfMass, wheelRadius, wheelWidth, wheels[{name,position,steer,drive,handbrake}], suspension*, maxSteerAngle, drive, maxEngineForce, gearRatios, finalDrive, automatic, topSpeedKmh, brakes, tire grip, downforce, drag} |
| `road` | `road` | `points` [[x,y,z]…], `width`, `closed`, `banking`, `thickness`, `samplesPerSegment`, `surface`, `edgeLines`, `shoulderWidth` |
| `checkpoint`, `startFinish` | `trigger` | `size` [x,y,z], `index` |
| `spawnPoint` | `spawn` | `gridIndex` |

Unknown keys are preserved. Files newer than the running Zino (`formatVersion` higher) are refused
with a clear message instead of being misread. Material presets: default, asphalt, concrete, grass,
dirt, gravel, carPaint, metal, rubber, glass.

## Safety
- Saves are atomic (`.tmp` + rename) and keep the previous version as `.bak`.
- Autosave writes `Cache/autosave/<scene>.autosave`; on open, a newer autosave offers recovery.
- Every load and save validates ids, transforms, parents (missing / cycles) and road data.
